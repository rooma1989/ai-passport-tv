小鼠电视 · 自建服务器

第一次设置

这台服务器还没有管理员。输入设置码，你就是管理员：之后可以添加频道、绑定小电视、邀请家人。

设置码只能用一次；每次重启服务器会换一个新的，直到管理员建好。

设置好了，你是管理员。接下来：

  1. 把这台手机的遥控加到主屏幕：打开手机遥控，用浏览器的「分享 → 添加到主屏幕」。
  2. 设置一台小电视：先给它刷好固件，让它进入配网，然后打开声波配网。 小电视的服务器地址填 （不用写端口）。 服务器地址填这台电脑在家里网络中的地址（例如 192.168.1.20，不用写端口）。
  3. 小电视连上以后会显示绑定码：在手机遥控里扫码或输入它，小电视就是你的了。
  4. 添加频道：在电脑上打开电脑版的「管理 → 频道表」，导入你自己的播放列表；或在手机遥控里订阅 B 站 UP 主。
打开手机遥控

这台服务器已经设置过管理员了。请在电脑版登录，或用已登录的手机打开遥控。

本软件不带任何频道、直播流、账号或代理，只播放你自己添加的来源。 请只添加你有权观看的内容，只在自己家里使用，不要把服务器或它的视频流分享给家以外的人。

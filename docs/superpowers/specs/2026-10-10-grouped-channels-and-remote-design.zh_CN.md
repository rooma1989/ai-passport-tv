# 频道分组与手机遥控 —— 设计

状态：2026-10-10 已确认。承接
[`2026-10-09-creator-channels-and-cast-design.zh_CN.md`](2026-10-09-creator-channels-and-cast-design.zh_CN.md)。

## 目标

1. **小电视**：直播、UP 主和投屏不再挤在一个 95 项左右的列表里。频道列表改成两级（先分组、再选台），看节目时长按上下键只在当前分组里换台。
2. **手机**：网页变成好打开的遥控器（短网址、只验证一次、能加到桌面、也能在小电视上扫码），分三个标签页：遥控、投屏（带可重播的历史）、UP 主。

## 已定事项

| 问题 | 决定 |
| --- | --- |
| 小电视列表 | 两级：先分组，再列出该组的台；长按确定键返回 |
| 分组 | 我的投屏、UP 主、央视、卫视、港澳台、国际、音乐、动画影视、其他；空的分组不显示 |
| 直播台归类 | 按台名自动归类，可在手机上改 |
| 打开网页 | 短网址 `iewww.com/tv`、只验证一次（180 天）、加到桌面、小电视上扫码 |
| 网页布局 | 底部三个标签：遥控、投屏、UP 主 |
| 视觉风格 | 暖墨色背景、朱红点缀、宋体标题和台名、琥珀色等宽字的台号屏；不用圆角卡片、蓝按钮和表情图标 |
| 历史 | 最近 50 次投屏，存在服务器上，所有手机共用 |

## 分组

- `server/channel_groups.py`（电视服务和中转共用）：固定的分组表和 `classify(id, name) -> 分组`：
  - `cast` → 我的投屏；`upNN` → UP 主；
  - 名字以 `CCTV` 开头 → 央视；
  - 名字含「卫视」（香港卫视除外），或地方台的 4K 频道（名字以 4K 结尾）→ 卫视；
  - 港澳台电视台的名字（凤凰、TVBS、东森、华视、民视、三立、中视、中天、台视、耀才、香港）→ 港澳台；
  - 只有拉丁字母的名字，以及 CGTN/CNA/NHK/BBC/RT 开头的 → 国际；
  - 含「精选」或「音乐」→ 音乐；
  - 一份固定的动画和电影名单（猫和老鼠、哆啦A梦、海绵宝宝、七龙珠、中华小当家、周星驰、让子弹飞、电影）→ 动画影视；
  - 其余 → 其他。
- 手动调整：`channel-groups.json`（`{"台 id": "分组"}`），只由中转（手机网页）写，电视服务读（`TV_CHANNEL_GROUPS_FILE`），和频道表一样
  「变了才重读」。不认识的分组名和坏文件都忽略并记日志。`channels.txt` 格式不变，`tools/channel_config.py` 照常可用。
- CONFIG 里分组名只发一次，每个台带一个编号：`"groups": ["我的投屏", …]`，`channel_list` 里每项 `{"id", "name", "g": n}`。
  这样 4.1 KB 的列表只多约 600 字节；每个台都带分组名会超过 7 KB 的 `TV_CONTROL_MAX`。

## 小电视

- `ui_menu`：在台这一级前面加一级分组。确定键打开分组列表，停在正在播的台所在的组；在某组上按确定，列出该组的台，停在正在播的台
  （不在这组就停在第一个）；长按确定返回上一级，在分组这一级长按则关闭。纯逻辑，有主机测试。
- 看节目时长按上下键：在正在播的台所在的组里切到下一个 / 上一个，循环。
- CONFIG 没有 `groups`（旧服务器）：所有台算一个组，菜单跳过分组这一级，和现在一样。
- 状态页：CONFIG 带了 `remote_url` 时，用它的二维码代替使用说明的二维码；没有就还是说明二维码。

## 手机遥控换台

- 中转的事件增加第三种：`switch`，带频道（`{"seq", "action": "switch", "channel"}`）。`SwitchWatcher` 收到后返回
  `("switch", 频道)`，设备已在该台时不动作。
- 电视服务在每次会话开始和结束时写 `now-playing.json`（`TV_NOW_PLAYING_FILE`）：频道 id、是否在线、设备是否声明支持切台、时间。
  对 `cast` 和 `upNN`，中转按自己在该台最后起播的视频补上标题。
- 中转自己读完整的频道表（`--main-channels`，就是那份 `channels.txt`），用来在网页上列出直播台。
- 网页上的错误提示：小智没在线、固件不支持切台（「请在小电视上手动换台」）、没有这个台。

## 手机网页

### 网址与登录

- nginx：`location ^~ /tv/` → 中转网页端口（网页和接口），`location ^~ /TV/R/` → 中转的扫码入口。`/TV/cast/?k=` 继续可用并跳转过去。
  `/TV/` 的使用说明页不变。
- 登录：`GET /tv/?k=<密钥>` 或 `GET /TV/R/<扫码码>` 生成一个随机会话，中转记下它和创建时间，并设置
  `tvs=<会话>; HttpOnly; Secure; SameSite=Lax; Path=/tv/; Max-Age=15552000`（180 天），然后跳到 `/tv/`。所有网页和接口请求都要有
  有效的会话 cookie 或密钥头，否则照旧 404。
- 二维码：`HTTPS://IEWWW.COM/TV/R/<扫码码>`，扫码码是 20 位 base32（A–Z、2–7，100 位随机）。全是大写，二维码可以用字母数字模式，
  只需第 2 版（25×25，纠错等级 L：47 个字符里用 43 个），状态页放得下。中转把这个地址写进 `remote-url.txt`，电视服务在 CONFIG 里以 `remote_url` 发给设备。它和
  配对令牌一样是明文传输；网页上可以换一个新扫码码，换了之后所有已登录的手机都要重新扫。
- 加到桌面：网页应用清单（名字「小智电视」、全屏、主题色 `#1c1915`、起始页 `/tv/`）和 180×180、512×512 两个 PNG 图标，由脚本画一次。

### 三个标签页

- **遥控**：琥珀色台号屏（`CH 02`、分组、标题），一排分组名，下面是该组带编号的台，点一下就换。「调整分组」开关打开后，每个台旁边
  可以选分组。
- **投屏**：粘贴框和「在小智上播放」；「放过的」：最近 50 次投屏（标题、B站/YT、日期），点一下重播，左滑删除。
- **UP 主**：增删 UP 主，显示「未看 n/20」；底部有使用说明入口；最底下是「换一个扫码码」。

### 接口（都要会话或密钥）

| 调用 | 作用 |
| --- | --- |
| `GET /api/state` | 正在播放、分组及其中的台、UP 主、历史、投屏 |
| `POST /api/switch {channel}` | 写一条 `switch` 事件 |
| `POST /api/cast {url}` | 同之前；同时记入历史 |
| `POST /api/history/play {site, id}` | 重播一条历史 |
| `DELETE /api/history/<site>/<id>` | 删除一条历史 |
| `POST /api/groups {channel, group}` | 设置或清除（`null`）某个台的分组 |
| `POST /api/code` | 换一个扫码码，所有会话失效 |
| UP 主相关 | 不变 |

### 历史

- 存在 `relay-state.json` 的 `history`：新的在前，最多 50 条，每条 `{site, id, title, at}`；重播一条会把它挪到最前。

## 出错处理

| 情况 | 处理 |
| --- | --- |
| 会话过期或扫码码已换 | 404；网页提示重新扫小电视上的码 |
| 分组文件坏了 | 忽略，全部按名字归类，记日志 |
| `now-playing.json` 缺失，或标为在线但超过 30 秒没更新 | 显示为不在线 |
| 两台手机同时操作 | 都能用，以最后一次换台为准 |

## 测试

- 主机测试：`classify` 对现有 88 个台名；分组文件的读取和坏文件；CONFIG 里分组的编码，以及有 12 个 UP 主时的总长度；`ui_menu` 两级、
  返回、打开时停在正在播的组、长按在组内循环、没有分组时的退化；会话 cookie 的签发、过期和作废；扫码码格式和二维码版本；历史的顺序、
  上限和去重；`switch` 事件以及不在线 / 不支持切台的回答；网页脚本用到的字段与接口一致。
- 设备测试：两级菜单、组内长按换台、手机换台、微信和相机扫状态页的码、加到桌面。

## 分步交付

1. 服务器和网页：网址与登录、加到桌面、新风格的三个标签页、历史、手机换台。不用刷固件。
2. 固件：两级菜单和组内长按换台（需要第 1 步下发的 `groups`）。
3. 固件：状态页的遥控二维码。

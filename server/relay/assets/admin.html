「重连」让设备断开再马上连上（新固件才认这个命令），封禁、解绑之后会自动做一次。 「重新配对」：设备擦过 flash、密钥变了时，10 分钟内它用新密钥连上来就会被记住；被拒的设备在「状态」里标着「密钥不匹配」。 旧固件的设备（legacy-…）不能解绑，先刷新固件再在命令行 adopt。

怎么更新固件：在插着设备的那台电脑上，用 Chrome 或 Edge 打开项目网站的「刷机」页， 连上设备后选「更新固件」：只写启动程序和固件本体，设置区不写，Wi-Fi、服务器地址和绑定都保留，设备不用重新配对。 网页串口只能在 https 页面或本机的 localhost 上用；设备插在家庭服务器那台电脑上时，在那台电脑上打开 http://localhost:8080/flash/。

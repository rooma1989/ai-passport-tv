电脑客户端

装在家里一台常开的电脑上，小电视的节目就从这台电脑来。

0.2.0 测试版。每个型号一次放一台小电视，在家里用手机遥控。安装包没有签名，第一次打开时 Windows 和 Mac 都会警告，下面写了怎么点。软件不带任何频道、直播源或账号，要看什么由你自己添加。

装好以后

Windows 提示「Windows 已保护你的电脑」

  1. 点「更多信息」。
  2. 点「仍要运行」。
  3. 「用户账户控制」点「是」，按向导装完。

Mac 提示「未打开"Xiaozhi TV"」

  1. 先把「Xiaozhi TV」从 DMG 窗口拖进「应用程序」，再从「应用程序」里打开。
  2. 被拦下时点「完成」（不要点「移到废纸篓」）。
  3. 系统设置 → 隐私与安全性 → 往下滑，点「仍要打开」，再确认并输入密码。
  4. 问能不能查找本地网络上的设备时，点「允许」。

第一次运行

  1. 任务栏或菜单栏出现小电视图标；第一次会自动下载视频组件，进度在图标的菜单里。
  2. 浏览器自动打开设置页，设置码已经填好：填名字，成为管理员。

连接手机、设置小电视

  1. 图标菜单 →「连接手机…」，手机相机扫二维码登录，加到主屏幕。
  2. 图标菜单 →「设置一台电视…」，用 Chrome 或 Edge 给插在电脑上的小电视刷固件。
  3. 小电视用声波配网（服务器地址已经填好），然后用手机扫码绑定。

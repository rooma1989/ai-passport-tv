# 小智电视电脑客户端（0.2.2 测试版）

把家里一台 Windows 电脑或 Mac 变成小智电视的「电视台」：电脑在后台取片源、转码，经家里的 Wi-Fi 送到小电视上；
手机在家里用浏览器遥控。装好以后只在任务栏（Windows）或菜单栏（Mac）里有一个小电视图标，不用打开任何窗口。

视频只在你家里的网络里走，不经过任何云服务器。设计和取舍见
[`2026-10-19-pc-client-architecture-design.zh_CN.md`](../superpowers/specs/2026-10-19-pc-client-architecture-design.zh_CN.md)。

**这个软件不带任何频道、直播流、播放列表、账号或 cookies。** 第一次启动时频道表是空的，要播什么由你自己添加
（频道表可以按链接读几个网上公开的第三方播放列表）。

## 测试版的限制

- **每个型号一次只服务一台小电视。** 一台星智 Cube 加一台 AI Passport 可以同时看；两台星智要等 1.0。
- **只能在家里遥控**（手机和电脑在同一个 Wi-Fi）。出门在外遥控是下一个测试版（0.3）。
- **安装包没有签名**：Windows 和 Mac 第一次打开时都会警告，下面写了每一步怎么点。正式版会签名。
- 刷固件用浏览器里的网页刷机（Chrome 或 Edge）；内置刷机、自动更新、语音识别是以后的版本。
- 打了「未验证」的步骤是照官方文档写的，作者还没有在真机上走过一遍。

## 你需要什么

- 一台**常开**的电脑：Windows 10/11（64 位）或 macOS 12 以上（Apple 芯片或 Intel 都行）。有人看电视时它不能
  关机；客户端会自己阻止电脑「闲置睡眠」，但合上笔记本盖子仍然会睡。
- 电脑和小电视、手机连**同一个家庭网络**（电脑插网线也可以，只要在同一个路由器下）。
- 一台小智电视：星智 Cube 1.54（小智 AI 外壳）或 FoloToy AI Passport。
- 刷固件时：一根能传数据的 USB 线，电脑上装 Chrome 或 Edge。
- 第一次运行要能上网：客户端会下载视频转换组件 ffmpeg（几十 MB，进度显示在托盘菜单里）。

## 第一步：下载

到发布页下载对应你电脑的文件（项目网站的下载页会自动帮你挑）：

| 你的电脑 | 下载 |
| --- | --- |
| Windows 10/11 | `XiaozhiTV-<版本>-windows-x64-setup.exe`（安装包，推荐）；`XiaozhiTV-<版本>-windows-x64.zip`（免安装版） |
| Mac，Apple 芯片（M1、M2、M3、M4…） | `XiaozhiTV-<版本>-macos-arm64.dmg` |
| Mac，Intel 芯片 | `XiaozhiTV-<版本>-macos-x86_64.dmg` |
| Linux（附带支持） | `xiaozhi-tv-<版本>-linux-x86_64.tar.gz`，见压缩包里的 `README-linux.txt` |

**Mac 是哪种芯片？** 点屏幕左上角的苹果菜单 →「关于本机」：写着「芯片 Apple M…」的是 Apple 芯片，写着
「处理器 Intel…」的是 Intel。

**核对下载（可选）**：发布页有 `SHA256SUMS-desktop`。Windows 在 PowerShell 里运行
`Get-FileHash .\XiaozhiTV-…-setup.exe`，Mac 在终端里运行 `shasum -a 256 ~/Downloads/XiaozhiTV-….dmg`，
算出来的一串字要和 `SHA256SUMS-desktop` 里那一行一样。

## 第二步：安装

### Windows

1. 双击 `XiaozhiTV-…-setup.exe`。
2. 如果出现蓝色的「**Windows 已保护你的电脑**」（SmartScreen）：点「**更多信息**」，再点「**仍要运行**」。
   这是因为测试版没有购买代码签名证书，不是文件坏了。（截图 TODO：SmartScreen 两步）
3. 「用户账户控制」问是否允许更改：点「**是**」。安装要管理员权限一次，用来装到「Program Files」和添加防火墙规则。
4. 按向导点「下一步」直到完成，勾着「启动小智电视」点「完成」。

安装程序会给小智电视加一条**只在「专用网络」上生效**的防火墙规则，小电视和手机才连得进来。如果你家的 Wi-Fi 在
Windows 里被标成了「公用网络」，托盘菜单会提醒你；改法：「设置 → 网络和 Internet → 点你的 Wi-Fi（或以太网）→
网络配置文件类型 → 专用网络」。

Windows Defender 偶尔会误报 PyInstaller 打包的程序。如果安装后程序被删除或隔离，先按上面的方法核对 SHA256，
再在「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」里还原，并欢迎在 GitHub 上报告。

### Mac

1. 双击 `.dmg`，在打开的窗口里**把「Xiaozhi TV」拖到「Applications（应用程序）」文件夹**。
   一定要先拖进去再打开：直接在 DMG 窗口里双击运行，macOS 会把它放在一个临时的只读位置，数据和登录启动都会出问题
   （托盘菜单也会提醒你）。
2. 打开「应用程序」文件夹，双击「Xiaozhi TV」。
3. macOS 会说「**未打开"Xiaozhi TV"**」或「无法验证开发者」：点「**完成**」（**不要点「移到废纸篓」**）。
4. 打开「**系统设置 → 隐私与安全性**」，往下滑到「安全性」，看到「已阻止"Xiaozhi TV"以保护 Mac」，点「**仍要打开**」，
   再点一次「仍要打开」并输入电脑的密码。（截图 TODO：隐私与安全性里的「仍要打开」）
   - macOS 12–14 也可以：在「应用程序」里**按住 Control 点「Xiaozhi TV」→ 打开 → 打开**。macOS 15 以后只能用上面的方法。
5. 之后再打开就不会问了（每次更新到新版本后会再问一次，同样处理）。
6. 如果 macOS 问「允许"Xiaozhi TV"查找本地网络上的设备吗？」点「**允许**」，否则它连不上家里的片源和小电视。
   如果打开过 Mac 的防火墙，它还会问是否允许接受传入连接：同样点「允许」。

Mac 上客户端只在屏幕顶端的菜单栏里有一个小电视图标，程序坞里没有图标，这是正常的。

### Linux（附带支持，未验证）

解压到主目录并改名为 `~/xiaozhi-tv`，运行 `~/xiaozhi-tv/xiaozhi-tv`；没有托盘的机器加 `--no-tray`，设置页网址会打印在
终端里。详见压缩包里的 `README-linux.txt`。

## 第三步：第一次运行

1. 启动后，任务栏右下角（Windows，可能藏在「^」里，可以把它拖出来）或屏幕顶端菜单栏（Mac）出现一个**小电视图标**。
2. 客户端第一次启动要准备一下：建数据文件夹、生成密钥；电脑上没有 ffmpeg 时自动下载，托盘菜单里显示
   「正在下载视频组件（ffmpeg）… 42%」。
3. 准备好后，**浏览器自动打开设置页**，一次性的设置码已经填好（设置码只在这台电脑上，不经过网络）。
   填家里的名字和你的名字，点「成为管理员」。（截图 TODO：设置页）
4. 以后点托盘图标 →「**打开电脑版**」就能回到这个后台，自动以管理员身份登录。

如果浏览器没有自己打开，点托盘图标 →「继续第一次设置…」。

## 第四步：连接手机

1. 点托盘图标 →「**连接手机…**」。浏览器里打开一个二维码页面。（截图 TODO：二维码页面）
2. 手机连家里的 Wi-Fi，用手机**自带的相机**扫二维码，打开后点「在这台手机上登录」。
3. 按页面提示把遥控「添加到主屏幕」，以后从主屏幕图标打开。

二维码几分钟内有效、只能用一次；过期了再点一次「连接手机…」。家人的手机可以每人扫一次；也可以在遥控里
「我的 → 让另一部手机登录」。

## 第五步：给小电视刷固件、配网、绑定

1. **刷固件**：小电视用 USB 线插在**这台电脑**上，点托盘图标 →「**设置一台电视…**」，会在浏览器里打开
   `http://localhost:8080/flash/`（必须用 **Chrome 或 Edge**；Safari、Firefox 不支持网页串口）。页面自己认芯片：
   - 星智 Cube 第一次刷要先**整片擦除**（会去掉原来的小智 AI 固件，要你打勾同意），以后再刷只更新。
   - AI Passport **绝不擦除**（里面有出厂写入的身份信息）。
   - 已经装着小智电视的设备，选「**更新固件**」：只写启动程序、分区表和固件本体，存 Wi-Fi、服务器地址和设备密钥的
     设置区不写，设置和绑定都保留。新版本改了分区表时页面会提前说明，只能清空重装（之后要在总后台「重新配对」）。
2. **配网（声波）**：小电视开机进入配网画面后，用手机打开配网页：扫小电视屏幕上的二维码，或在手机浏览器里打开
   `http://<电脑的局域网地址>:8080/tv/wifi`（设置完成页上也有链接）。填 Wi-Fi 名称和密码，「服务器」一栏已经自动填成
   这台电脑的地址，点「发送」，把手机音量调大、靠近小电视（半米以内）。
3. **绑定**：小电视连上后显示「BIND THIS TV」和 6 位数字的绑定码。用已登录的手机扫小电视状态页的二维码，或在遥控
   「我的 → 绑定新设备」里输入那串码（输入框会弹出数字键盘）。10 分钟里同一个手机地址错 5 次、或全部加起来错 30 次，
   就暂停绑定（最多 10 分钟）；错满 30 次时所有未绑定的小电视还会换新码。旧版本留下的 20 位绑定码，小电视下次重连后
   会显示成 6 位数字。
4. **添加频道**：在电脑版（托盘 →「打开电脑版」）→ 总后台 →「频道表」里从网址或文件导入播放列表，或者选一个那里列出的
   公开播放列表点「读取」，再点**央视**或**卫视**、「全选」、**加入频道表**、**保存**，央视和各省卫视就一次加好了
   （详见 [`docs/selfhost/` 第三步](../selfhost/README.zh_CN.md#第三步添加频道你自己的)）。以下是网上公开的第三方播放列表，
   内容由其维护者负责，本项目不提供也不保证任何直播源；请只添加你有权观看的内容。在手机遥控的「订阅」里可以添加
   B 站 UP 主和剧集。

**电脑的地址要一直不变**：笔记本换了网络、或路由器给电脑换了 IP，小电视就找不到它了。最稳的办法是在路由器里给电脑
「固定 IP / DHCP 静态分配」（可选）。

| 菜单项 | 作用 |

| 设置一台电视… | 打开网页刷机（`localhost` 的刷机页） |

| 不让电脑睡眠 | 打勾：小智电视运行时电脑一直不闲置睡眠（随时开小电视都能看）；不勾（默认）：只在有小电视在看、或有手机在听时不睡，最后一台关掉 2 分钟后恢复。两种都不会让屏幕常亮 |
| 登录时启动 | 开机登录后自动运行（默认打开） |
| 这是我家的网络 | 回答一次后就不再出现。之后笔记本只在这个网络上对外开放端口（网页、小电视）；在别的网络上（比如咖啡馆）只有这台电脑自己能用，菜单里写「不在家里的网络上」。换了路由器算新的网络：在家里再点一次 |
| 打开日志文件夹 / 导出诊断信息… | 出问题时用：诊断信息是桌面上的一个 zip，里面没有密码和密钥，需要时你自己发给帮你的人；什么都不会自动上传 |
| 重启电视服务 | 小电视连不上、画面卡住时先试这个 |
| 退出小智电视 | 停掉一切；小电视会显示「服务器没有回应」 |

再次双击「小智电视」图标不会开第二个，而是直接打开电脑版。

## 数据、更新和卸载

| 系统 | 数据（数据库、密钥、频道表） | 日志 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\XiaozhiTV\` | 同一个文件夹里的 `logs\` |
| Mac | `~/Library/Application Support/XiaozhiTV/` | `~/Library/Logs/XiaozhiTV/` |
| Linux | `~/.local/share/xiaozhi-tv/` | `~/.local/state/xiaozhi-tv/logs/` |

- 数据文件夹里的 `secrets/` 是密钥，备份时要像密码一样保管。
- **更新**：下载新版本，Windows 直接运行新的安装包（会先关掉正在运行的小智电视），Mac 把新的拖进「应用程序」替换。
  数据保留。测试版不会自动更新。
- **卸载**：Windows 在「设置 → 应用」里卸载（防火墙规则和登录启动项一起删掉）；Mac 先在菜单里「退出小智电视」，
  再把「应用程序」里的「Xiaozhi TV」拖到废纸篓，并删掉 `~/Library/LaunchAgents/io.github.ai-passport-tv.XiaozhiTV.plist`。
  两种方式都**保留数据文件夹**，确定不要了再手动删除。

## YouTube（可选）

YouTube 默认关着；B 站和直播频道不用它也能看。打开它是给已经有办法从这台电脑访问 YouTube 的家庭用的：**本项目不提供
代理，也不介绍怎么获得代理。**

1. 在电脑版（用管理员登录）打开 **设置 → YouTube**，选 **本机**。
2. 代理：填你的代理软件给这台电脑的地址，例如 `http://127.0.0.1:端口` 或 `socks5://127.0.0.1:端口`；或者点
   **自动检测**，它读系统代理（macOS 的网络代理设置、Windows 的代理设置、Linux 的 `https_proxy` / `all_proxy`
   环境变量）并把找到的填进去。代理软件开着 TUN（增强）模式、或者本来就能直连 YouTube 时，留空。
3. 点 **保存**。第一次会下载两个 YouTube 组件 yt-dlp 和 deno（约 80 MB，经这个代理；也可以填一个下载镜像前缀：用来替换下载地址里的 `https://github.com`，
   要整个网址的 GitHub 加速站写成 `https://加速站/https://github.com`），
   每个文件都按程序里写死的 SHA-256 核对。进度就显示在这一节里。
4. 点 **测试**：解析一个公开的测试视频，用大白话告诉你结果（「成功：12 秒」「连不上 YouTube：检查代理」「需要登录：
   导入 cookies」）。
5. **Cookies**：YouTube 常常要求代理、机房的地址「登录证明不是机器人」。这时导入一个 `cookies.txt`（Netscape 格式）：
   用一个**小号**，在浏览器的无痕（隐私）窗口里登录小号、打开 YouTube，用导出 cookies.txt 的扩展只导出 youtube.com，
   然后直接关掉无痕窗口（不要退出登录，退出会让 cookies 作废）。客户端只留 youtube.com 和 google.com 的条目，存在
   `<数据目录>/youtube/cookies.txt`（只有你能读），页面上只显示条数。这个文件就是小号的登录凭据：不要发给别人。
6. YouTube 改版很勤。视频放不出来时，点 **检查更新**、**更新 yt-dlp**（新版本按它发布页自己的 `SHA2-256SUMS` 核对）。

改了不用退出程序：保存后只重启变了的部分（只改代理就只重启 YouTube 的那个小服务）。之后 YouTube 视频、频道（UP 主）
和播放列表（剧集）和云端一样用。「自己的节点」给自己架了 YouTube 节点的人用（`secrets/youtube-node.json`）。

## 常见问题

- **小电视显示「服务器没有回应」**：电脑开着、小智电视在运行吗？电脑和小电视在同一个路由器下吗？Windows 上家里的网络是
  「专用网络」吗？同一型号的另一台正在看吗（测试版一次一台）？
- **手机打不开遥控**：手机要连家里的 Wi-Fi（不是流量），而且和电脑在同一个网络。手机上开着 VPN 或代理软件时也可能连不到电脑，
  先关掉。
- **显示的地址不对（198.18.x.x、100.x.x.x、VPN 的地址）**：客户端用电脑上连着家里路由器的 Wi-Fi 或有线网卡的地址，不用 VPN、
  代理（TUN 模式）、Tailscale、Docker、虚拟机的网卡；旧版本记错的地址会重新识别。还是不对的话，在数据文件夹的
  `config.toml` 里写上正确的地址（`[server] device_address = "192.168.1.20"`，不带端口），再点「重启电视服务」：重启会重读
  `config.toml` 和电脑的地址（端口和 `bind` 还是要退出客户端再打开才生效）。路由器给电脑换了地址（DHCP）时，客户端运行中
  大约半分钟内会发现（开着 VPN 或代理时最多五分钟左右）。
- **托盘菜单说某个端口被占用**：8097、8098 是小电视固定要用的端口，菜单里会写出是哪个程序占着，把它关掉后点「重启电视服务」。
  8080 被占时客户端会自动换一个端口，手机扫码时不用管。
- **刷机页说找不到设备**：换一根能传数据的 USB 线；用 Chrome 或 Edge；Windows 上可能要装 USB 串口驱动（CH340/CP210x）。
- **更新后小电视一直在打开、或者屏幕上写着 `RE-PAIR THIS TV IN ADMIN`（被拒绝）**：小电视的设置区被清空过——
  v0.2.0-beta 及更早的刷机页选「更新固件」时其实把设置区也写成了空白（之后的版本已经修好），清空重装也会这样——它生成了
  新的设备密钥，家庭服务器还记着旧的，所以拒绝它。先用声波配网让它重新连上家里的 Wi-Fi，再打开总后台的「设备」：被拒的
  那台标着「密钥不匹配：点「重新配对」」，点「**重新配对**」，10 分钟内它会自己连上并被记住，频道和绑定都还在。
- **B 站视频、UP 主或剧集打不开，一直在加载**：先在这台电脑的浏览器里打开 bilibili.com。也打不开的话，是这台电脑的网络到不了 B 站：
  路由器或家长控制屏蔽了 B 站（在路由器里放开），或者代理软件（Clash、Surge 等，尤其是 TUN 模式）把 B 站的流量分给了不能用的节点。在代理软件的规则里让 B 站直连：
  `DOMAIN-SUFFIX,bilibili.com,DIRECT`、`DOMAIN-SUFFIX,bilivideo.com,DIRECT`、`DOMAIN-SUFFIX,hdslb.com,DIRECT`，
  或者暂时关掉 TUN 模式。B 站是国内网站，直连也更快。
- **合上笔记本盖子后小电视断了**：合盖会让电脑睡眠，这是系统的规定。需要合盖使用的话，在系统的电源设置里改合盖行为，
  或者用一直开着的台式机、迷你主机。

## 进阶：NAS、Docker 和命令行

不想在电脑上装客户端、或者家里有一直开着的 NAS / 迷你主机的，可以用同一个核心的其他跑法：Docker 镜像、群晖/绿联/
威联通的容器、直接用 Python 运行。见 [`docs/selfhost/`](../selfhost/README.zh_CN.md)。那些方式没有托盘，第一次设置要在日志
里找设置码。

开发者文档（代码在哪、怎么构建、CI、和核心之间的接口）：[`developer.zh_CN.md`](developer.zh_CN.md)。

  一次登录（Mac 上经代理、不带 cookies 时每次都要求）。
